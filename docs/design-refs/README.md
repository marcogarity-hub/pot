# Design references (Lazyweb)

Pulled 2026-11-13 from Lazyweb for the Lane 4 UI. These are for looking at only. Don't copy any brand's assets.

Lazyweb collection with all 15 screens (private to Marco's account):
https://www.lazyweb.com/agentic-search/0b5917bc-e071-4439-81d7-4881aae3c774

## 1. Group payment progress bar — `progress/`
| File | App | What to look at |
|---|---|---|
| 01-gofundme-goal-dashboard.jpg | GoFundMe (desktop) | Progress toward a goal next to donation stats. Closest match to "pot filling up". |
| 02-monarch-savings-goal.png | Monarch (desktop) | Big balance header, a progress bar, and a list of contributions under it. |
| 03-farfetch-tier-progress.png | Farfetch (mobile) | A simple mobile bar showing "$X of $Y" and how much is left. |
| 04-partiful-chip-in-setup.png | Partiful (mobile) | Host sets an amount per person. Guests say they paid when they RSVP. Shows the "chip in" setup, not the progress view. |
| 05-billy-group-split.png | Billy (mobile) | Each person's share listed by name, with a "Share with Group" button. |

Note: Lazyweb has few mobile screens of a group pool with a progress bar. For our status screen, combine the GoFundMe/Monarch bar with the per-person list from Billy.

## 2. Join with invite link — `invite/`
| File | App | What to look at |
|---|---|---|
| 01-ourcal-join-via-link.png | OurCal | Join a private group from an invite link. Has a field to paste the link by hand. |
| 02-life360-invite-code.png | Life360 | Boxes for each code character. Pasting the whole invite message fills in the code. |
| 03-finch-invite-redeem.png | Finch | Modal: tap the link or paste a friend code. |
| 04-beli-invite-accepted.png | Beli | "You're in" screen with the inviter's photo. Useful for the step after joining. |
| 05-zoom-join-by-link.png | Zoom | Join by ID or link. Shows which account you'll join as. |
